🛡️ Meu Servidor Ragnarok Online — Website Oficial

Projeto web desenvolvido para gerenciamento e apresentação de um servidor privado de **Ragnarok Online**, com foco em organização de informações, experiência do usuário e integração com sistemas do servidor.

---

## 📌 Sobre o Projeto

Este site tem como objetivo centralizar informações essenciais do servidor, oferecendo aos jogadores uma plataforma clara, funcional e segura para acesso a conteúdos como:

- Página inicial institucional
- Downloads do cliente
- Rankings do servidor
- Base de conhecimento (Wiki)
- Área preparada para futuras integrações com sistema de contas

O projeto também funciona como um **laboratório prático** para aplicação de conceitos de desenvolvimento web adquiridos na faculdade e em estudos autodidatas.

---

## 🚀 Funcionalidades Atuais

- Estrutura MVC utilizando Laravel
- Sistema de rotas organizado
- Templates com Blade
- Layout responsivo
- Páginas:
  - Home
  - Download
  - Ranking
